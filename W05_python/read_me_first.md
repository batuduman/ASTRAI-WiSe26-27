Please install Jupyter Notebook via Anaconda by following these steps:

1. Download and install Anaconda:
* Go to https://www.anaconda.com/download/success?reg=skipped
* Choose Anaconda Distribution
* Follow the installation guide for your system: https://www.anaconda.com/docs/getting-started/installation

2. Launch Anaconda Navigator:
* Anaconda Navigator should open automatically after installation. Later, you can open it from the Start menu (Windows) or the Applications folder (macOS).
* Click Launch under the Jupyter Notebook tile. If you see Install instead, click that first.
* Jupyter Notebook will open in your web browser.
* For additional help, here are two short video tutorials. Some screens may look different in the current version.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; - Windows: https://www.youtube.com/watch?v=UTqOXwAi1pE&t=197s

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; - macOS: https://www.youtube.com/watch?v=0xYWWFOEBi8

3. Download the course materials to your local computer:
* **Recommended**: Do a `git pull` to get all ASTRAI materials. If you've forgotten how, check the Week 2 slides.
* **Alternative (not ideal)**: Download the materials manually by opening the ASTRAI repository, clicking the green Code button (top right, above the file list), selecting Download ZIP, and unzipping the folder. This gives you only a one-time snapshot: you’ll have to re-download the whole folder each time materials are updated. Please use `git pull` if you can.

4. Open the notebook:
* In Jupyter Notebook, navigate to the folder where you saved the ASTRAI materials.
* Open the `W05_python` folder, then open `A_Gentle_Intro_to_Python.ipynb`.
* Follow the instructions in the notebook to learn the basics of Python. Feel free to draw on other resources (YouTube, online tutorials, or AI tools) whenever they help you learn better.
